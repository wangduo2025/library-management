# 图书管理系统

## 简介
用 Java + MySQL 做的简易图书管理系统，有控制台和图形界面两个版本。

## 技术
- Java
- MySQL
- JDBC
- Swing（图形界面）

## 已完成
- [x] 连接数据库
- [x] 添加图书
- [x] 查看所有图书
- [x] 修改图书价格
- [x] 按ID删除图书
- [x] 按书名搜索
- [x] 控制台菜单
- [x] 图形界面版（Swing）

## 运行说明
1. 导入项目到 Eclipse
2. 确保本地已安装 MySQL 并创建 `library` 数据库和 `books` 表
3. 修改代码中的数据库密码为你的密码
4. 运行 `BookSystem.java`（控制台版）或 `BookGUI.java`（图形界面版）
